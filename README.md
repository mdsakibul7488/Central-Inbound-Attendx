# Central Inbound AttendX

Pathao Central Inbound Attendance System — PWA built with HTML/CSS/JS.

## Features
- Fingerprint / PIN based check-in & check-out
- Geofencing (location-based radius check)
- Hold-to-submit circle animation
- Google Sheets integration
- Admin panel with pending approval, block/unblock
- Bangla / English language switch
- Multi-account support (up to 3 per device)
- Monthly cycle (26th to 25th)

## Setup
See `SETUP-GUIDE.md` for full instructions.

## Tech Stack
- Frontend: HTML, CSS, JavaScript (PWA)
- Backend: Google Apps Script
- Hosting: Netlify (auto-deploy via GitHub)
- Database: Google Sheets
